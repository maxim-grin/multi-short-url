# multi-short-url

A deliberately small URL shortener, written once in Python and deployed to the
homelab and several clouds so the platforms can be compared. The app is not the
interesting part; running it everywhere is.

## How it works

- POST a long URL and get a short one back.
- `GET /<prefix>/<code>` redirects with a 302. The prefix (for example `g` for
  Google Cloud) names the instance that holds the code. It is not part of the
  code.
- Codes are random and generated by the server.
- Only the last 1000 URLs are kept.
- Every store supports "create only if absent", so two requests can never claim
  the same code.

## Status

Early. The core is not written yet and nothing is deployed. Planned targets: the
homelab (Kubernetes through ArgoCD, with its manifests in a separate repo), AWS,
Azure, Google Cloud, Cloudflare, Oracle Cloud and Vercel.

## Design choices

- Python 3.12+, standard library only in the core, no web framework. Each
  cloud's store client is an optional extra.
- Terraform deploys every cloud, with one build and publish per cloud. There is
  no image shared by all of them.
- uv for the environment, pytest, ruff and mypy. Tests come first.
