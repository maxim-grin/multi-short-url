# multi-short-url

A deliberately small URL shortener, written once in Python and deployed to the
homelab and several clouds so the platforms can be compared. The app is not the
interesting part; running it everywhere is.

## How it works

- POST a long URL and get a short one back.
- `GET /<prefix>/<code>` redirects with a 302. The prefix (for example `g` for
  Google Cloud) names the instance that holds the code. It is not part of the
  code.
- Codes are random and generated by the server.
- Only the last 10,000 URLs are kept (`SHORTENER_KEEP`).
- Every store supports "create only if absent", so two requests can never claim
  the same code.

## Status

Early. The core and a standard-library server are written; nothing is deployed.
Planned targets: the homelab (Kubernetes through ArgoCD, with its manifests in a
separate repo), AWS, Azure, Google Cloud, Cloudflare, Oracle Cloud and Vercel.

## Design choices

- Python 3.12+, standard library only in the core, no web framework. Each
  cloud's store client is an optional extra.
- Terraform deploys every cloud, with one build and publish per cloud. There is
  no image shared by all of them.
- uv for the environment, pytest, ruff and mypy. Tests come first.

## Running

```bash
cd app
SHORTENER_PREFIX=homelab SHORTENER_BASE_URL=http://localhost:8080 \
  SHORTENER_DB_PATH=/tmp/links.db uv run python -m shortener
```

`SHORTENER_PREFIX`, `SHORTENER_BASE_URL` and `SHORTENER_DB_PATH` are required;
`PORT` defaults to 8080 and `SHORTENER_KEEP` to 10000. Anyone who can reach it can create links, with no login.
The 1-per-second creation limit is best-effort, and a patient flood can still
push out the stored links. The homelab instance is reachable only on the local
network.

## Releases

Images publish to `ghcr.io/maxim-grin/multi-short-url` on `v<semver>` tags only.
The tag must equal the `version` in `app/pyproject.toml`, or the build fails.
The image runs as uid 10001, stores data at `/data/links.db` (mount a volume with
fsGroup 10001) and needs only `SHORTENER_PREFIX` and `SHORTENER_BASE_URL`.
